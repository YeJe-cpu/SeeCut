# 10 · 剪映分层工程（skill v3 交付物之一）

> 目标（作者定）：把成片**分图层**推进剪映草稿，用户能在剪映 UI 里微调。**不许把合成好的整片放主轨。** 2-4.1 实测作者验收："能推到剪映里还能微调，到这一步已经不错"。
> 依赖（**可选**）：剪映草稿引擎 jianying-headless（上游 github.com/mcncarl/jianying-headless，个人学习非商业协议，**不随本 skill 分发**，用户按其协议自行安装；作者本机是 Intel 适配版 + 剪映 11.5.0）。没装也能跑：本管线始终产出**编辑器无关的分层工程包**（`jianying/layers/` + `plan.json`），装了引擎就能一步导入剪映。

## 一 · 打标契约（写 master.html 时就打好）
- **信息层每个元素**加 `data-layer="显示名"`，可选 `data-layer-cat`：
  `evbg`（满屏证据底，在人像下面）/ `card`（证据卡、章节卡）/ `cardimg`（卡里的图、标签）/ `hl`（荧光）/ `title`（标题、chip、印章、手写字）/ `hand`（手绘圈/线）。默认 `card`。轨道从下到上：evbg → 人像 → card → cardimg → hl → title → hand。
- **嵌套**：父元素里的 `data-layer` 子元素会单独成段，截父元素时自动隐藏。粒度按"用户可能想单独挪/删的东西"来定。
- **人像**：`#personWrap`（外框，带卡化白边/圆角）里放 `<img id="person">`；外框的位置/大小变化就是人像状态（全屏/分屏/小窗…）。
- 纸底、噪点这类背景不打标。

## 二 · 流程
```bash
node scripts/jianying_layers.mjs build            # → jianying/layers/：纸底.png、png/*.png（信息层）、人像_状态N.mp4、原声.m4a、manifest.json（含音效候选 events）
python3 scripts/jianying_plan.py jianying/layers/manifest.json --name "<片名>_分层工程" --out jianying/plan.json \
        [--sfx sfx_plan.json] --preview jianying/preview.mp4
cd "$JIANYING_HEADLESS_ROOT"   # 你自己装好的 jianying-headless 目录
python3 engine/jy14_headless.py build --plan <abs>/jianying/plan.json --out <abs>/jianying/work/build
python3 engine/jy14_headless.py verify-build --build <abs>/jianying/work/build
# publish 前：剪映主程序必须退出（托盘助手 TrayHelper 在跑不影响，已实证）；先备份 root_meta_info.json
python3 engine/jy14_headless.py publish --build <abs>/jianying/work/build --audit <abs>/jianying/work/publish
```
- `project.json` 要写 `source`（口播源片路径），用于抽原声。
- **核对**：publish 后首页索引条数 +1、原有条目逐条未变；把预览和成片同时间点抽帧对比（稳态画面应一致）。

## 三 · 能力边界（2-4.1 实证）
- ✅ 多轨分层、线性关键帧（位置/缩放/不透明度）、透明 PNG、音效轨。
- ❌ **剪映引擎不收带 alpha 的视频** → 信息层只能是透明 PNG（入场动画变成淡入；手绘"画出来"、弹簧回弹在草稿里是静态图 + 淡入）。
- ❌ **关键帧要求素材从头开始（source_start=0）** → 人像按状态切成独立视频。
- ❌ **Intel 上代码原生导出跑不通**（引擎写死 arm64 + 中文路径 + 上游 writer 问题）→ 用户在剪映 UI 里手动导出；`--preview` 出的是 ffmpeg 合成预览，文件名必须注明"非剪映原生导出"。
- ⚠️ 坐标约定：scale=1 = 适应画布，x/y 以半画布为 1、y 向上为正（2-4.1 推算，作者 UI 验收未报偏差）。
- ⚠️ 蒙版单位文档没写 → 人像卡的白边/圆角直接烤进人像视频，不用蒙版。
- ✅ 人像中途隐藏再出现：脚本自动识别，隐藏段不出人像，前后加 3 帧不透明度淡出/淡入（v3.1 修，Round2-4.2 回归通过）。
- ✅ 30fps 等不能整除的帧率：时长按帧时刻换算并不超过媒体实测时长（v3.1 修，避免 build 报 Source trim exceeds）。

## 四 · 所以要两份交付
剪映草稿里动画会"素"一些，所以同时交**渲染成片**（HyperFrames 全效果、原声）给用户直接用；草稿（带音效轨）给用户微调。
