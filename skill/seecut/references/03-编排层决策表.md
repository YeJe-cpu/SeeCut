# 编排层 · 文本驱动决策表（Round1 核心交付 · v2）

> 数据来源：8条参考片样本、**536拍**，经"文案先行"重跑（口播原话↔画面打法）+ 按"这句功能"聚合。这是**可泛化、文本驱动**的编排规则——不是复刻片段，是"给我一句口播，我知道画面该怎么处理"。
> 配套原料：`beat-sheets-v2/*.v2.md`（每拍=口播原话+功能+人像层+信息层+动效+转场）。

## 0 · 两层模型（先破"A-roll/B-roll"二分）
参考片不是"A-roll vs B-roll"，而是**一条连续音轨 + 两个可叠图层**：
- **音轨**（数字人/真人配音）= 全片连续骨架，定时间轴。这才是真"A-roll"。
- **图层① 人像层**：状态可变（半身/PIP撕纸框/角落小圆/隐去），**不必每拍出现**。
- **图层② 信息层**：截图/录屏/chip/卡/大字/3D，盖在音轨上。

**一句话总纲**：**说话人露不露，取决于这句是"对你说"还是"给你看"。**
- 对你说（情感/观点/收尾/纠偏/建信任）→ **露**（半身或PIP）。
- 给你看（演示/信息/证据/列举）→ **藏**（隐去或缩角落），信息层当主角。

## 1 · 核心流程（Round2 直接用）
1. 转写用户口播 → 逐句。
2. 给每句打**功能标签**（下表13类之一）。
3. 查下表 → 定〔人像层状态〕+〔信息层内容〕+〔动效/转场〕。
4. 出 SHOTBOOK（每拍：口播原话 → 功能 → 人像层 → 信息层 → 素材需求）。

## 2 · 功能 → 打法 决策表（★数据背书，括号=536拍中占比/次数）
| 口播这句的功能 | 人像层（主导） | 信息层（主导） | 说明 |
|---|---|---|---|
| **hook钩子**（开篇留人） | PIP撕纸框(38%) | 满屏热点截图/图 + 手绘涂鸦标题徽章 | 人压底陪衬，标题砸爆点词 |

| **讲底层机制/原理** | 隐去(58%) | 截图 + 命令chip + 概念卡+手绘箭头 + 证据镜 | 图解结构 |
| **引用文档/源码** | **PIP撕纸框(56%)** | 满屏该文档截图 + chip | 人压底"陪看"文档 |
| **列举并列项/命令** | 隐去/PIP | **命令chip纵向staggered堆叠 / 进度清单列表** | N项→N chip |

| **收尾道别/复盘** | **半身(70%)** / 隐去(复盘时) | 空(人说) / 进度清单1~N轮播(复盘) | 收尾露人；复盘走清单 |

## 3 · 人像层状态机（何时露/缩/藏，独立速查）
- **露半身** = 收尾(70%) · 建立信任 · 纠偏/定调(部分) —— "人正对你说话"的时刻。
- **PIP撕纸框陪伴** = hook · 引用文档 · 边讲边陪。
- **角落小圆(角落头)** = 情绪痛点 · 信息密集需进一步让位。
- **隐去** = 举例演示(77%) · 讲机制(58%) · 满屏证据 —— "信息才是主角"的时刻。
- 切换动效：露→缩用 PIP缩放；缩→藏用整屏切换/背景模糊让位；藏→露用硬切。

## 4 · 信息层选型（内容特征 → 组件，接组件层）
- 有真实页面/操作 → 截图/录屏 + 证据镜（滚动/放大/圈注/下划线）
- 多个并列项/命令 → 命令chip堆叠 / 进度清单
- 具体数字/阈值 → 数字大卡
- 概念关系/分类 → 概念卡+手绘箭头
- 情绪痛点 → 3D卡通隐喻（缺口，需生成/降级角落头+引用气泡）
- 章节切换 → 章节卡 + 像素/线稿图
- 纯观点无据 → 信息层留空、只露人

## 5 · 三类用户输入的适配器（人像层原料从哪来）
| 用户输入 | 人像层原料 | 怎么再构图 |
|---|---|---|
| 录屏(左下小脑袋) | 已含小脑袋 | 抠出当PIP/角落；需满屏时盖住 |
| 真人半身口播 | 一条完整半身 | 按状态机 切半身/缩PIP/隐去 |
| 数字人(音轨+完整出镜图) | 生成的完整半身 | 同上；大部分隐去，少数露 |
→ 三者**编排引擎（本表）完全共用**，只差"人像层原料"这一层适配。

## 6 · 诚实边界
- 表中占比是8样本536拍的统计倾向，**不是硬规则**——同一功能人像层常有多选(如定调可露可藏)，最终看这句"对你说 vs 给你看"的成分。
- "灵活"类(定调/给数字/转折)需结合上下文，不能纯查表。
- 3类输入里"数字人"样本尚未实测，录屏/半身可先跑验证。
- 真正验收=Round2 拿真素材出样片（作者定）。
