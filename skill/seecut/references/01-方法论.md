# 《参考片剪辑方法论》· Round1 交付（初稿）

> 依据：10 条参考片样本（8完整+2部分）经 agy 逐拍拆解 + 我抽帧核（抽样40%准确）+ 跨样本聚合 80+ 条"情境→打法"。
> 输出格式学 student-kit `MOTION_PHILOSOPHY.md`；组件层对齐 talkcraft 108卡 / student-kit。
> 定位：**参考片=高质量数字人口播科普（作者定）**，富设计、丝滑、信息密度极高。目标=让 agent 能剪出这种效果。
> ⚠️ 标 [核] = 已抽帧或跨样本≥3次证实；标 [观] = agy 观察待再核。

---

## 0 · 一句话定性
**数字人口播打底，把满屏让给高密度信息层。** 同一条固定数字人素材做多种"再构图"（PIP撕纸框 / 满屏 / 隐去 / 角落头 / 半身），每个名词都有画面响应，语义拍卡点、极致快切少呼吸。信息层=真实截图证据 + 弹字/命令卡 + 手绘注解 + （部分创作者）3D卡通隐喻。

## 0.5 · 战略层：为什么这么剪（从战略到策略）
> 摸清底层意图，才不会机械抠像。参考片这套之所以成立，是5条战略在支撑，下面每条战略→落到具体策略/组件。
1. **数字人口播 = 生产可规模化**（战略）→ 一条音轨骨架 + 可再构图人像，不依赖真人拍摄，能批量复制。（策略：两层模型，人像层大部分隐去/缩小）
2. **信息层高密度 = 制造"干货感"**（战略）→ 每个名词都有画面响应、快切少呼吸，用视觉密度兑现"信息量大、值得看/收藏"的心理预期，拉完播率。（策略：法则3每名词有响应 + 节奏快切）
3. **人像露/藏 = 情感与信息的节奏调度**（战略）→ 在"亲和信任"和"信息效率"之间动态平衡。（策略：**"对你说vs给你看"总纲** + 人像状态机）
4. **手作质感 = 差异化人格 + 亲和**（战略）→ 涂鸦/撕纸框/像素图，区别冷PPT与纯AI，立"用心的极客笔记"人设。（策略：设计层手绘描边 + 组件层手绘涂鸦标题/像素卡）
5. **真实证据优先 = 可信度**（战略）→ 讲什么给什么真实截图/录屏，不mock。（策略：信息层证据镜 + 法则4真图硬规）
> **一句话战略**：用数字人把生产做轻，用高密度信息层把"干货感"做足，用人像露藏调度信任节奏，用手作质感立人设——低成本、可复制、还显得用心。

## 1 · 核心法则（跨样本归纳）
1. **一拍一主体，说完让位**：任一时刻视觉重心只有一个（host 或 一张信息卡）；新元素只在语义拍边界进场，不一句一元素堆积。[核]
2. **host 是可变构图的图层，不是主角**：全片 host 在 PIP / 隐去 / 角落头 / 半身 间切换，**多数时间隐去或缩小**，把画面让给信息。构图靠剪辑再构图同一条素材，不是生成不同构图。[核]
3. **每个名词都有画面响应**：口播提到命令/文件/数字/概念，0.3~0.8s 内必有对应 chip/卡/大字/箭头弹入同步。[核]
4. **真实证据优先**：讲工具/操作/数据，满屏铺**真实截图/录屏**（不 mock），配证据镜（滚动/放大/圈注/下划线）。[核]
5. **背景让位**：上层弹信息时，底层截图高斯模糊+压暗，绝不与前景抢注意力。[核]
6. **快切少呼吸**：平均每拍 ~3-4s，密集处 1-2s；只在章节卡/收尾/真人定调时留短呼吸。[核]
7. **真人回切建信任**：每逢定调观点 / 纠偏认知 / 转折 / 收尾，硬切回 A-roll 半身正机位、清空浮UI、用眼神锁定。[核]
8. **手绘感统一质感**：涂鸦标题/箭头/撕纸PIP框/像素插画构成"极客手作笔记"的统一手绘质感，区别于冷 PPT。[核]

## 2 · 设计层 The Reference（视觉系统）
- **色板逻辑（角色化，非装饰）**：强调红/珊瑚（钩子/关键词/警示数字）· 科技蓝（品牌/命令/技术）· 米白波点纸底（章节/信息卡底，护眼笔记感）· 分类绿（模块命名）· 警示黄橙（高亮/箭头）。**每色承载一个含义**。[核]
- **字体**：主标题=粗黑体带手绘描边（手作笔记感）；命令/代码=等宽 mono；正文卡=现代无衬线粗体。[核]
- **幕底三态**：信息期=高斯模糊截图/录屏；转场/章节期=复古米白波点像素幕底；共情/定调期=真实工位环境景深。[核]
- **构图系统（★核心，Round2 直接套）**：host 五态 —
  - **半身**（真实工位）：hook/定调/纠偏/收尾，建信任。
  - **PIP框内**（撕纸拍立得/圆形）：伴随讲解、总述，人退居边缘让位。
  - **角落头**（底部/角落小圆）：列痛点/信息密集时进一步缩小。
  - **隐去**：深度原理/满屏证据/章节卡时彻底藏。
  - **满屏**（人极小或无）：纯截图/录屏证据。
  - 画幅混合：样本里有 3:4 竖屏也有 16:9 横屏，方法论构图无关、按渠道定。[核]

## 4 · 编排层 · "情境→打法"决策树（★心脏，Round2 直接用）
> ⚠️ **本节已升级**：以独立的 **《编排层-文本驱动决策表.md》**（8样本536拍数据背书、13类功能→打法）为准。核心总纲：**说话人露不露=这句"对你说 vs 给你看"**。下方6类是v1初版聚类，保留参考。
> 跨 10 样本 80+ 条规律聚类成 6 类。用法：给用户口播每一拍打情境标签 → 查对应打法。

### A｜有匹配素材（截图/文档/录屏/实拍）→ 满屏铺 + host降级 + 证据镜
- 引用文档/热点/源码 → 满屏铺该截图 + host降PIP或隐去 + 涂鸦标题强调爆点词。[核]
- 论证资源丰富/海量列表 → 全屏截图**纵向匀速滚动**(缓推拉) + host降左下PIP。[核]
- 演示实操/工作流/点击 → 满屏录屏 + host隐去 + 证据镜(光标/滚动/高亮)。[核]
- 展示长报告/长文档 → host隐去 + 截图整屏 + 自下而上匀速滚动展全貌。[核]
- 引用跑分/评测数据 → host缩右上PIP让位 + 截图弹入 + 左右图文对齐。[核]
- 教命令/快捷键 → 满屏CLI/IDE录屏 + 命令chip弹入视觉中心 + 终端同步高亮。[核]

### B｜无素材·纯观点/概念/机制 → host态调整 + 概念可视化
- 讲概念结构/分类 → host隐去 + 概念标签卡 + 手绘箭头建上下级。[核]
- 讲抽象底层机制 → **强视觉物理比喻**(打印机吐无限纸卷/施法升维) + host圆形PIP辅助解说。[观]
- 讲阈值/关键数字 → 保留界面 + 居中巨型数字卡 + 拟人警示标签。[核]
- 定调观点/主结论 → A-roll半身推近 + 真实工位 + 无贴片干扰。[核]
- 纠偏认知/反常识("不是A是B") → 瞬间硬切A-roll半身正机位 + 清空界面 + 眼神冲击。[核]

### C｜列举/清单/并列 → chip堆叠 或 进度清单 + 背景模糊让位
- 列举N并列项/命令 → N个chip纵向/水平staggered堆叠弹入 + 背景模糊让位。[核]
- 列举等价操作(拖拽/按键A/按键B) → 多chip垂直/水平staggered。[核]
- 列举避坑/误区 → 高对比概念标签卡("3个误区") + 保留界面锚点。[核]
- 痛点清单 → 进度清单列表纵向堆叠 + host降角落PIP。[核]

### D｜情绪/痛点/共情 → 3D卡通隐喻 或 角落头+引用气泡
- 病理性/情绪痛点 → host隐去 + 3D卡通角色苦恼抓头插画 + 手绘箭头戳痛点。[观]（部分创作者路线，需生成素材）
- 抛痛点/设问 → A-roll角落头 + 头顶引用气泡列举痛点 + 背景静态让位。[核]
- 模拟反面低效操作 → 趣味3D角色冲突动画(怪兽击倒小人) + 极简让位。[观]

### E｜结构性节点（章节/转折/收尾）→ 换幕 / 硬切真人 / 复位
- 进大章节/新模块 → 整屏切换章节卡(像素/线稿/录屏) + host隐去 + 停1-2s定音 + 左上角换涂鸦徽章。[核]
- 转折/新话题 → 硬切回真人半身居中 + 剔除浮UI + 眼神锁定。[核]
- 收尾/复盘 → 1~N进度清单轮播 + 像素背景；结束Slogan → host复位居中PIP + 纯渐变背景。[核]

### F｜纯画质/沉浸证明（特定题材：游戏/生图/视频）→ 满屏B-roll
- 展示画质/场景细节 → 整屏B-roll(游戏录屏/实拍漫游) + host隐去 + 纯画质承接论点。[观]
- 复刻/1:1还原证明 → 第一人称交互漫游 + 大纵深展示真实性 + 手持微推拉当"物理证据"。[观]

## 5 · 节奏与音频
- 节奏：平均~3-4s/拍，密集处1-2s；章节卡/收尾/真人定调留短呼吸。前段高频轰炸(2s一次)、中段原理放缓(~5s)、尾段真人回抓。[核]
- 音效：章节换幕带卡通提示音；数字/chip弹入带轻音效。**BGM/字幕在剪映补，不在本方法论**。[核]

## 6 · 反模式（不要做）
- ❌ 一句一个新元素堆积（凌乱根源）；新元素只在语义拍边界进。
- ❌ 裸大字/裸章节卡凑数——每拍要有具体视觉承载（对齐 memory 温感手写地板）。
- ❌ 上层信息不模糊背景 → 前后景文字打架（对齐 memory 画面丰富两规则）。
- ❌ 四张同色同纹样章节卡("又来了"不是"翻页")——每章一套主题色+相关线稿motif。
- ❌ 用代码 mock 假 UI 冒充真截图——有真实页面就截真图。
- ❌ host 长期占据画面主中心抢信息位。

## 7 · Round2 应用指引（拿到用户素材怎么走）
1. **理解素材**：转写口播 + 盘点用户有哪些截图/录屏/图 + 认 A-roll 构图（数字人可任意再构图）。
2. **逐拍打情境标签**（A/B/C/D/E/F）→ 查本决策树 → 生成 SHOTBOOK（每拍：情境→打法→组件→素材来源）。
3. **缺素材处理**（按组件表"素材来源"列）：证据类→要用户截图/我方Playwright截；生成类chip/卡→设计生成；3D卡通/像素→AI生图生视频或降级线稿。
4. **搭建渲染**：talkcraft卡(蒙皮改CONFIG) + student-kit整屏切换 → Remotion渲。
5. **收尾**：作者剪映补 字幕+BGM。
