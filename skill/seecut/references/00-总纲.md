# 00 · 总纲（v3，唯一规范源的最高层）

> 本文件 16 条是全 skill 的"宪法"。其它 references 只负责展开细节，**不得与本文件矛盾**；发现矛盾=以本文件为准，并在交付报告里写明"某文件某处与总纲冲突"，不自行调和。
> 改规则只改本文件或对应细节文件，并记入根目录 `CHANGELOG.md`；**禁止在正文里叠"某日某人定"的补丁层**。

## 一 · 目标与信源
1. **目标 = 网感口播精剪**：口播（真人或数字人出镜）打底，把画面让给高密度信息层（真证据 + 卡片/chip/大字 + 手作质感 + 弹簧动效），人像按"对你说露、给你看藏"调度。风格规范在 `01-03`。参考片可选：用户自备同风格片段放 `金锚集/`。
2. **信源优先级**：`03-编排层决策表` / `01-方法论` > `02-设计令牌` > 其它文件（用户自备参考片时，参考片 > 以上）。上下冲突时上层赢。

## 二 · 画面怎么剪
3. **两层模型**：连续音轨是骨架；人像层（半身/卡化小窗/角落/隐去）+ 信息层（证据/chip/卡/大字/手作）叠在上面。人像露不露 = 这句是"对你说"还是"给你看"（`03` 决策表）。
4. **证据优先**：口播提到真实的产品/网页/文档/数据/操作 → **必须先尝试拿真证据**（用户素材 > 自己截图/录屏 > 实在拿不到才降级）。真证据当信息层主角，**满屏铺是参考片的正常做法**（配证据镜：滚动/放大/圈注/下划线，前景弹出时背景模糊压暗让位）。
5. **禁假证据**：不得用抽象占位窗口、伪代码网格、假 Mac 窗口/假 App 界面、与话题无关的装饰窗口拼贴去冒充证据或"填满"画面。概念卡/chip/数字卡/清单等设计元素可以用，但不能装成截图。
6. **无证据时**（纯观点句，或确实拿不到）→ 干净设计底（米白点阵纸）+ 前景元素扛密度，或人像半身露脸（决策表：纯观点则露脸）。**不许空拍**：信息拍前景有效元素 ≥ 2。
7. **审核与名誉安全**：画面里不得出现可读的敏感字（下载/反爬/扫码/搬运/联系方式/引流站外/价格违规承诺等），每张证据截图入片前必须读图核一遍。**截图打码**：证据截图里的**来源标识**（站名、logo、人名、账号/头像）默认模糊，出处写"实截（已打码）"；**被讨论的产品名**（如帖子标题里的 ChatGPT）先保留，**交付报告里列出来问用户**要不要打（自己做样片无所谓，正式发布时由用户定）。
8. **名词响应 + 不抢拍**：口播每个具体名词/命令/数字约 1 秒内有画面接住；payoff 元素锚在关键词被说出的那一帧（逐词时间戳），绝不早于词。
9. **内核令牌全片不变**（`02` §0-A）：弹簧回弹 + 错峰级联、粗黑无衬线、色族（砖红/青柠/琥珀）、手作质感、人像卡化、三禁（不纯黑白硬碰、不刺眼纯红大字报、不硬切无缓动）。
10. **人像连贯**：全片人像卡化形态统一，位置/大小变化必须跟着功能走、过渡平滑，**不无故换位置换形状**；无脸连续 ≤ 5 秒。
11. **组件必须先调官方库（硬规则）**：`npx -y hyperframes@latest catalog` 查 HF registry（394 项，大写 `HTTPS_PROXY`）。SHOTBOOK 每个镜头的"选哪张卡"**必须写出 registry 组件名，或写明库里为什么没有**；交付报告列出用了哪些组件。手绘类优先用 `assets/hf-hw/`（已抽好的 hw-callout-circle / hw-underline / hw-arrow）。库不可用 = 预检不过，先修，不许以此为由手搭。

## 三 · 怎么验
12. **渲染铁律**见 `08-避坑SOP`（人像 img 逐帧、绝对时间 seek、opacity+set+to、长任务看门狗）。
13. **质检闭环**（`06-质检闭环spec`）：硬门（3A 几何 + 硬伤清单）全过 → **两两对比"新版 vs 上一版"**（交换 A/B 位置各跑一次，两次一致才算数）决定是否采纳新版；对照参考片参考片只用来找差距方向，不打分。**不追任何百分比**。
    **迭代要有肉眼可见的进步**：每一版至少改一处"对照参考片找出的大差距"（证据、版式、密度、人像调度这类），硬伤小修补合并进同一版，不单独占一版。
14. **agy 调用纪律**：每次 `--new-project`；JSON schema 结构化输出；评委隔离（视频复制到系统 tmp 再评，不让它读到工程源码）；指纹核（agy 照抄的画面文字必须能在本片源码或 fp-manifest.txt 里找到）+ 时长核；agy 陈述的关键事实要抽帧核实再采信。

## 四 · 何时停
15. **停止条件**：硬门全过，且（新版对比不胜上一版 或 **已做到第 3 版** 或 只剩肉眼看不出的小修补）→ 交付。卡住（环境缺依赖、素材拿不到、规范冲突）= 停下带证据报告用户，不自判"够了"，也不无限死磕。长任务**每 15 分钟往 runlog 写一行进度**，用户随时能看到没在空转。
16. **交付**：①**渲染成片**（HyperFrames 全效果）落 `~/Downloads`；②**分层工程包**（纸底/人像/信息层透明 PNG/原声/音效计划 + 剪映 plan，编辑器无关）；③若本机装了剪映引擎（jianying-headless，可选，**不随 skill 分发**）→ 登记成**剪映分层草稿**，音效放草稿的音效轨，成片只带原声；**没装剪映引擎 → 音效直接混进渲染成片**（音效不丢）。音效按 `09-音效规范`（开头 0.5 秒内必须有一个抓耳音效）。字幕、BGM 留给用户在剪映做。
