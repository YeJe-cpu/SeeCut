# 几何规则自检 · spec（管线新增护栏，2026-09-20 作者拍板）

> 定位：位置歪/圈错位/撞位/露脸空档/同词重复这类 = **几何问题**，agy 单帧/540p 看不出、我抽帧也易漏(2-3 v3.1 栽此)。用**确定性几何检查**兜住，别老靠 作者肉眼。是质检闭环硬门 H1 的实现（`06-质检闭环spec` §二）。
> 怎么跑：由 `scripts/geom-check.mjs` 用 playwright `page.evaluate(()=>el.getBoundingClientRect())` 在**每个信息拍的稳态帧**读元素 bbox，跑下面规则，FAIL 当场报警+定位到秒/元素。渲染前几秒级、免费。
> 🔴 **实现铁律(2-3.1 静默卡死 25min 的教训)**：**整套 scrub+读 bbox 塞进浏览器内一次 `page.evaluate` 跑完**(2.7s)，**绝不每帧一次 Node↔浏览器往返**(942 次往返延迟堆叠≈挂死)。且必须套超时看门狗+进度打印(见避坑SOP §三.5)，别让自检本身静默空转。

## 检查项（逐条，输出 过/FAIL + 秒 + 元素）
1. **元素不重叠/不撞位**：给需要判定的元素打 `data-check="box"`(标签/卡片/chip/胶带/窗口/大字)。两两 bbox 重叠面积 > 各自 15% → FAIL（标签压卡、胶带盖角标、卡叠卡）。允许"背景托板"用 `data-check="bg"` 豁免(它本就该被叠在上层)。
   - **★框-人像重叠检测(2026-09-21，2-3.1 回灌)**：把 `#person` PIP 也纳入重叠检测——任何 `data-check="box"` 与人像 PIP 的 bbox 重叠 > 0(或留 <5% 安全边) → FAIL（"清单/卡骑脸"）。**agy 跨 v5/v6 持续幻觉"清单骑脸人像"，此几何数据(实测 0 重叠)可凭数据 dismiss**——是"用几何驳 agy 假警报"的又一实例。
2. **圈/下划线/箭头锚准关键词**：给手绘标记打 `data-anchor="<目标元素id>"`。标记中心与目标元素 bbox 中心距离 > 目标高度的 40%，或标记未覆盖目标 60% 宽度 → FAIL（圈歪/圈偏/圈到空白/圈错行）。2-3 末尾红圈圈到空白 = 这条能抓。
3. **同词重复上限**：扫可见文本节点，同一关键词(如"豆包")在同一拍/相邻拍出现 > N 次(默认 2) → 警告（同质轰炸）。
4. **无脸空档**：按人像层 `#person` 的显隐时间轴，统计最长连续无脸时长 > 5s → FAIL；并交叉口播功能(自述/感叹/总结句必须有脸) → 这些句子所在帧无脸 → FAIL。
5. **信息密度**：每个信息拍稳态帧，`data-check="box"` 元素数 < 2 或最大空白连通区 > 画面 45% → 警告(空拍/飘空卡)。
6. **timing 词级**：每个 payoff 元素 `data-word="<关键词>"`，其揭示帧的时间 < seg_words.json 里该词起始时间 → FAIL(抢拍)。

7. **信息拍不空拍（2026-09-21 修订，撤回"背景须满屏"）**：⚠️ 原"背景空白<35%=FAIL"**已废**——它逼出了 v6/v73 满屏 busy 底(素人最丑)，方向错了(干净底 v3 反而素人 90)。**改为只抓真空拍**：某信息拍稳态帧**前景有效元素(卡/chip/大字/PIP/手作) < 2 个 且 大片空白 > 画面 55%** → 才 FAIL(v3 早期"空纸飘一张小卡"的病)。**干净透气的底不算问题、别再逼满屏内容**。背景清爽度归 作者肉眼+素人，几何只兜"前景太空"。
8. **★弹簧 overshoot 检测（驳 agy"无弹簧"假警报，2026-09-21 新增）**：给带弹簧入场的元素在其入场窗口内**采几帧量 scale 曲线**，确认存在"冲过 100%(如 106%)再回落"的 overshoot(back.out)。**有 overshoot=达标、直接驳回 agy"无弹簧/匀速"的误报**(agy 540p 单遍看不出)；无 overshoot=真软塌、改。→ 客观数据说话，不跟 agy 辩。

## 用法与边界
- **打标成本**：要执行窗在 composition 里给元素加 `data-check/data-anchor/data-word` 属性。一次加、复用。
- **与 agy 分工**：几何自检抓"能算的"(位置/距离/时长/时间/弹簧)；agy 硬伤清单(H2)与两两对比抓"要看的"。agy 说法与几何数据冲突时以数据为准。
- **回灌**：用户肉眼发现的新几何类问题 → 加成新规则并记 CHANGELOG（如"箭头方向错"→加方向检查）。
- 现状（v3.1）：`scripts/geom-check.mjs` 已实现第 1/2/4/6/8 条为 FAIL、第 5 条为 WARN（第 3 条同词计数未实现，靠 H2 兜）；**新增"被人像盖住"**：每个 box 取 5 个采样点，≥3 个点最上层是人像 → FAIL（不管人像多大；Round2-4.2 v2 的字卡被盖 1.5s，旧检查和 agy 都漏了，新检查抓到）。

## 配置契约（v2，脚本不再写死路径）
工程目录（build）里放 `project.json`，渲染与几何自检都读它：
```json
{"html":"master.html","fps":25,"width":720,"height":1280,"duration":17.88,
 "timeline":"master","person_dir":"person","person_img_id":"person","person_wrap_id":"personWrap",
 "steady":[4.65,6.7,9.0],
 "spring":[["#s1_cut",4.28],["#s3_vs",8.5]]}
```
- `steady`：每个信息拍的稳态秒（撞位/圈锚/空拍在这些时刻检）；`spring`：[选择器, 入场秒]，检入场 0.6s 内 scale 峰值 >1.02。
- composition 必须暴露 `window.__timelines[timeline]`（GSAP 主时间轴）；人像 `<img id=person_img_id>` 放在 `#person_wrap_id` 外框里。
- 跑法：`node scripts/geom-check.mjs <build>`（退出码 0=全绿）；`node scripts/render.mjs <build> probe|full`。工程目录先 `npm i playwright-core`（别 sudo）。
