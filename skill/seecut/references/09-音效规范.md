# 09 · 音效规范（v1，skill v3）

> 来源：2-4.1 执行窗《音效规范 v0》一线实配（AV5 数字人，12 个落点，作者试听认可"整体还好、总比没有强"）+ 维护者《音效库台账》+ 作者要求"开头 0.5 秒给一个醒目音效"。
> 音效库：`$JIANJI_SFX_DIR`（默认 `~/Downloads/音效`，39 个）。台账：`references/sfx/音效库台账.md`（人读，含★首选清单）/ `.json`（脚本读）。

## 一 · 流程（4 步，工具全自动算，执行窗只负责"挑点 + 挑声音"）
1. **列候选事件**：`jianying_layers.mjs` 输出的 `layers/manifest.json` 里有 `events`（每个信息层元素出现/换状态、人像过渡的时刻）。
2. **挑落点**（执行窗判断，写 `sfx_choices.json`）：对照 SHOTBOOK 每镜的功能和文案语义，只挑"有意义的拍点"：换幕、证据落地、结论/盖章、翻车、设问、列举编号。**不逢动必响**。每个落点写 `t`（画面事件时刻）、`kind`、`sfx`（台账文件名）、`why`。
3. **算与查**：`python3 scripts/sfx.py plan --choices sfx_choices.json --voice <原声> --words seg_words.json --duration <秒> --out sfx_plan.json`
   - 自动算：起点偏移 + 取整到帧、跳过开头空白、只取第一下、按人声峰值定音量。
   - 自动查：开头抓耳、密度、低频重击压字、慎用音效、同一音效用太多次。**有 ⚠ 就改 choices 重跑，直到没有 ⚠，或者在报告里写清为什么保留。**
4. **落地**：有剪映引擎 → `jianying_plan.py --sfx` 进剪映草稿的音效轨，成片只带原声；**没有剪映引擎 → `sfx.py mix` 混进渲染成片**。音效是在推剪映之前就算好的，不依赖剪映。
5. **用户自己的音效库**：`sfx_ledger.py <文件夹> --out 台账.json [--listen]` → 自动实测起音点/第一下长度/共几下，按文件名猜类别，`--listen` 让 Gemini 补听感；`sfx.py plan --ledger 台账.json --sfx-dir <文件夹>`。skill 自带的台账只描述作者本机音效库（版权原因不随仓分发音效文件）。

## 二 · 映射（按类别挑；下表文件名是作者本机音效库里的例子，换成你库里同类的声音即可）
| kind | 画面事件 | 首选 | 备选 |
|---|---|---|---|
| hook | **开头 0-0.5s 抓耳（必须有）** | 叮当声(dingdongSound) | 叮叮_ / 重磅出场 |
| whoosh | 滑入 / 换幕 / 人像缩窗 | 转场-唰 | another转场（同一片里 2 次以上就换着用） |
| pop | 卡片 / chip / 像素弹出 | 字幕出现 | 叮叮_ |
| impact | 印章砸下 / 大字砸入 / 结论落定 | 咚-重击 | 咚一声another |
| ding | 要点出现 / 编号 / 步骤完成 | 叮一声 | 叮叮_ / 叮当声 |
| page | 翻页 / 换图 / 清单轮播 | 翻页( | 快速翻页声（连续翻多张） |
| click | 按键 / 点选 / 光标 | 金属咔嚓 切换页面 | 鼠标点击 |
| error | 红叉 / 翻车 / 错误示范 | 错误提示 | 玻璃碎（很严重的翻车） |
| correct | 对勾 / 达成 | 答题正确 | — |
| money | 价格 / 到账（语义真是钱） | 支付宝到账金币掉落 | 收银机 |
- 手绘圈 / 下划线 / 荧光笔：**不配**（库里没有笔刷声，已记缺口）。
- 设问卡：用 ding，不用"疑问"（卡通滑笛，agy 评出戏）。
- 梗音效（圣光/咩咩咩/火车/着火/彩票/妈妈牛来）：一条片最多 1 次，语义必须特别贴。

## 三 · 对齐（sfx.py 已内置）
- **起音点**：台账 `trim_start` = 能量包络首次到峰值 10% 的时刻（不是 -45dB 静音检测，那样弱起音会偏小 100-180ms）。剪映里 `source_start_us = trim_start`。
- **一个文件里有几下的**（咚一声 3 下、鼠标点击 6 下、疑问 5 下…）：只取第一下（`first_hit_len`）。
- **偏移**：pop/ding/page 等 = 元素出现帧；impact = 出现帧 **+0.12s**（弹簧落地那帧）；whoosh = 切换帧 **−0.08s**（让"唰"跨过切点）。**向上取整到帧**（声音不能早于画面）。
- **画面配合**：剪映草稿里信息层淡入提前 1 帧起、2 帧淡满（`jianying_plan.py` 已内置），否则音效响时元素还是透明的。
- **质检**：带音效版音轨减无音效版 = 纯音效轨，测起点，偏差 ≤50ms（约 1 帧）算过；落点前后各抽一帧，确认画面事件已可见。

## 四 · 密度与音量（sfx.py 自动查）
- **任意 3 秒最多 2 个；全片平均 ≤0.7 个/秒**（开头 hook 不计）。同类连续元素（两枚 ✓chip）只配第一个。
- **音量**：按人声峰值算，音效峰值落在人声峰值下方 −16 ~ −11 dB（pop/ding −16、whoosh −15、error/page −14、impact/hook −12）。剪映 volume 一般 0.05-0.25。
- **关键词避让**：低频重击（impact）不要压在口播关键词中间，会吃字 → 挪到词说完那一帧（sfx.py 会给出建议时刻），或降 3dB。

## 五 · agy 听评怎么用
- `agy_read.sh 带音效成片.mp4 "音效是否贴合画面和语义？有没有太密、太吵、抢人声？"`：**只信整体判断**（密度、风格割裂、刺耳、抢人声）。它说"第几秒是哪个声音"常常说错（2-4.1：报 13 个实为 12 个，把"咚"说成蜂鸣）。最终以用户人耳为准。
