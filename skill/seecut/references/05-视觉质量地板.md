# 参考片 · 视觉质量地板 / 审美对齐清单（Round2执行窗必达）

> 来源：agy 实测对比 A(round2样片) vs B(参考原片13) + 我抽帧核实 + student-kit卡库排查。2026-09-19。
> 定位：这是**硬地板**——达不到就是"营销号模板拼凑感"（round2 v1 的病）。方法论§3组件层/§4编排层的补充。
> 一句话病根：**round2 = 剪辑软件默认件拼凑；参考片 = 完整平面设计规范(Design System) + 细腻动态设计(Motion Design)。**

## 🔴 三条最致命（改完立刻质变）
1. **禁止"人脸高斯模糊循环当背景"**（round2 最掉价的病，14-22s全犯）。
   - 正确：人隐去时，背景 = **真实截图/录屏** 或 **米白/浅暖灰微噪点纸质 / 点阵网格(Dot Grid)画板**（像Notion/杂志）。**永远不要把主讲人虚化铺底。**
2. **禁止刺眼纯红大字报**（round2 用 #FF0000 级红底白字，像街头促销）。
   - 正确配色：**米白/象牙底 + 深炭黑字(不用死黑) + 克制强调色(科技蓝/牛油果绿/复古砖红)**；文字框一律圆角+四周留padding，不撑满边缘。
3. **禁止硬切/瞬移/默认几何件**。
   - 正确：所有卡片/箭头**缓入缓出(ease-out)+错落出场(stagger)+缩放遮罩过渡(scale+mask)**，配清脆pop/按键音；装饰用**手绘涂鸦/荧光笔/像素/撕纸/贴纸**，不是直角纯色块+默认红箭头。

## 信息层"千层饼"密度（每个信息拍必达）
参考片每个信息拍是**分层叠加**，不是"一个小卡飘在空背景上"：
```
底层：低对比真实文档/录屏 或 纸质/点阵画板
 中层：优雅浮现的卡片/chip（跟口播节拍一拍一落、stagger）
  下层：圆角柔和阴影的真人小窗（讲解员位）
   底部：字音同步字幕条 + 手绘/像素点睛
```
- **禁**：空拍(只有大头在说)、裸大头特写顶画面、满屏截图留大黑边、一屏只飘一个小卡。
- 每个信息拍 ≥ 2 个分层元素；讲重点可整屏换成像素插画让大脑换挡。

## 人像层"卡片化"（不是顶画面的大头）
- 讲干货概念 → 真人退成**白色圆角边框+柔和阴影的小卡**，置中下方(讲解员位)，给信息腾舞台。
- 讲金句/定调 → 丝滑放大到**中景半身**(带顶空、与前景模型/后景书架融合)，不是怼脸大头特写。
- 引用截图 → 人可缩PIP，但PIP要**有装饰边框**(撕纸/圆角+阴影)，不是光秃秃小圆。
- **禁**：全程大头特写顶中上部、怼镜头太近、发箍小蜜蜂裸出镜。

## 组件来源=两仓混用（★上游修正，别只用talkcraft）
- **talkcraft(108卡)**：偏 dev-craft/几何。
- **student-kit(406卡)**：`Vox Explainer`106 + `Kallaway`300，**编辑感/丝滑感更接近参考片**——有 `section.tornstrip`(撕纸)、`cutout`(抠图)、`highlight`(荧光圈注)、`stamp`(邮戳)、`collage`(拼贴)、`stat.giant-left`(大数字)、`stat.odometer`(数字滚)、Kallaway的丝滑motion。**参考片的手作/编辑感这些卡才有。**
- **引擎可混**：Remotion(.tsx)与HyperFrames(.html)只在单个合成文件内二选一，**最终成片各渲片段→ffmpeg/剪映拼**即可混用（参考片肉眼就是混的）。别再"选A/B"。

## 背景/纸质规范
- 信息期底：米白/浅暖灰 + 微噪点纸质 或 极客点阵网格；文字深炭黑。
- 实拍期底：布光的极客书房(整齐书架/暖光台灯/双屏冷蓝光/高达模型作前景锚点)，大光圈景深虚化——**冷暖对比、色温统一**。round2 的杂乱客厅+歪挂画+乱电线是反例。
