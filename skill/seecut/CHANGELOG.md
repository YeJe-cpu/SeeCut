## v2.0-beta（2026-09-23）· 顶层重构：生产与质检统一到"复刻参考风格"
依据：作者本地记录（未收录） + 校准实验 `agy验收留档/08、09`。

**为什么改**
- v1 的 agy "像参考片几成"分数与用户肉眼反向（2-3.1：干净 v3 35% / 假满屏 v7.3 68%；用户判 v3 好），同片两次打分差 20 分，修真 bug 分数不动 → 无法当迭代信号。
- 生产端（设计令牌 §3"默认干净"）跟着素人尺走，质检端（agy spec"满屏镜像/死磕95"）跟着参考片尺走 → 两把尺分家。
- 素人 prompt 给参考原片 62/45 分、给干净仿制品 90 分：它量的是"清爽克制"，不是参考片。
- 当年判丑的"满屏"是**假证据满屏**；错的是"假"，不是"满"。

**改了什么**
- 新增 `references/00-总纲.md`：15 条最高规则 + 信源优先级（原片 > 逐拍拆解 > 决策表/方法论 > 设计令牌）。
- 背景规则（`02` §3）：有据段铺真证据（满屏是正常做法）/ 无据段半身或干净底 / **禁假证据**；撤销"默认干净、真素材执行窗不主动够"。
- 新增"找真证据"环节（SKILL 第3步、`04` 证据计划列、`scripts/grab_evidence.mjs`、敏感字读图核）。
- 素材分类（`02` §6.5）：按"有没有完整口播人像 A-roll"分，数字人完整半身归①。
- 质检：`06-agy自闭环质检spec` → `06-质检闭环spec`。硬门 H1 几何 + H2 硬伤清单；采纳用两两对比（交换位置两次一致才算）；参考片只找差距不打分；停止条件 = 连续 2 次不胜或到 v5；删除百分比阈值、"死磕95"、"维护者"熔断。
- 评委：删 `prompt/放开挑刺.md`、`prompt/素人评测.md`；新增 `prompt/对比评委.txt`、`prompt/硬伤清单.txt` + JSON schema。
- 脚本：删 `capv3`/旧 `render`/旧 `geom-check`/`run_agy_safe.sh`（路径写死）；新增 `_common.mjs`、`render.mjs`、`geom-check.mjs`（读 `project.json`，无写死路径）、`agy_judge.py`（`--new-project` + schema + 指纹核 + 时长核 + 交换位置共识）、`preflight.sh`。几何自检把"无弹簧"从提示升为 FAIL。
- 金锚集：用途改为"学手法 + 找差距"；新增锚9（样本04 半身分屏定调）；按"功能 + 有据/无据 + 人像形态"挑锚。
